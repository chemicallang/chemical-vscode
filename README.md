## Chemical Programming Language


Chemical is a High Performance Native Programming Language.

You can find more information about it here.

[Github](https://github.com/chemicallang/chemical)

### Do a Hello World

Save this in `src/main.ch`

```chemical
public func main() : int {
  printf("Hello World");
  return 0;
}
```

and save this in `chemical.mod`

```
application main

source "src"

import std
```

> Open chemical.mod, Press the play button in top right corner
